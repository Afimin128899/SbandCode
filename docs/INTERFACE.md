# SbandCode: понятный интерфейс

## Направление

SbandCode — рабочий инструмент для программирования с телефона, а не
маркетинговый лендинг. Главный маршрут: выбрать модель и папку, описать
задачу, проверить результат. Существующие вкладки «Чат», «Инструменты»,
«Настройки» сохранены.

Тёмный графит сохранён. Мягкий синий выделяет основные действия и выбор;
красный обозначает ошибки и удаление. Логотип не перерисовывается.
Без декоративных градиентов, новой библиотеки компонентов и сетевых шрифтов.

Поиск ui-ux-pro-max вернул неподходящие структуры лендингов. Они не
использованы; рекомендации для Jetpack Compose применены к семантике,
подписям контролов и прокрутке.

## Визуальные правила

Источник цветов и типографики: `ui/Theme.kt`.

- Фон: `#14161C` (`surface`).
- Панели: `#1D2028` (`surfaceContainer`).
- Основной текст: `#F4F5F7` (`onSurface`).
- Пояснения: `#B8C0CF` (`onSurfaceVariant`).
- Основное действие: `#B5C8FF` (`primary`).
- Ошибки: `#FFB4AB` (`error`).

Семантические пары `on*` задаются в теме. Экраны используют эти роли,
а не собственные цвета. Недоступные действия используют стандартное
понижение контраста и семантику disabled.

Системный Android sans-serif поддерживает кириллицу и масштабирование.
Моноширинный шрифт остаётся для кода. Заголовки — semibold, основной
текст — обычный, высота строк 25 sp / 21 sp.

Контент выровнен влево. Поля — 24 dp; расстояния — кратные 4 dp.
Строки действий имеют минимум 72 dp, кнопки-иконки — область 48 dp.
Страницы ограничены шириной 840 dp, но заполняют узкий экран.
Высота текстовых строк не фиксируется, пояснения могут переноситься.

`ActionRow` — общий компонент для действия с иконкой, названием и
пояснением. Он использует кликабельный Material Surface, включая
обратную связь на нажатие, роль кнопки и недоступное состояние.

## Структура

```text
Чат
  История        Выбор модели        Новый чат
  Приветствие и примеры / Переписка
  Рабочая папка
  Ваша задача
  Параметры                 Стоп / Отправить

Инструменты
  Текущий проект и рабочая папка
  Изменённые файлы, Git, сайт, профили
  Linux, навыки и MCP

Настройки
  Подписки, API, локальные модели, лимиты
  Папка, уведомления, правила агента
  Резервная копия и восстановление
  Дополнительно: конфигурация, перезапуск, удаление
  О приложении
```

Примеры задач только заполняют черновик. Они не отправляют сообщение,
не запускают команды и не выдают разрешений.

Для локальной модели в режиме «Чат» вместо примеров показано пояснение
об отсутствии доступа к файлам и кнопка включения режима «Агент» с
предупреждением о более медленной работе.

Папка нового чата выбирается прямо над полем ввода. У существующего
чата отображается его папка без возможности незаметно её поменять.

У каждого чата есть видимое меню: переименование, экспорт, удаление.
Долгое нажатие также сохранено. Рабочая папка помогает различать чаты.

Правила агента имеют подпись поля, состояние сохранения и сообщение
о результате. Дополнительные настройки сворачиваются. Удаление всех
чатов выделено цветом, пояснением и прежним диалогом подтверждения.

## Проверка

```sh
python3 -m unittest discover -s tests -v
gradle --no-daemon :app:compileDebugKotlin
```

Первый тест проверяет реальные цвета в `Theme.kt`: контраст обычного
текста не ниже 4.5:1, читаемость пояснений и отдельный цвет ошибки.
Он не проверяет расположение элементов, работу кнопок или компиляцию.

Workflow **Check Android UI** запускает тесты палитры и компиляцию Kotlin
на pull request либо вручную. Он не собирает нативный движок или APK.
Для устанавливаемого APK остаётся workflow **Build SbandCode APK**.

Перед выпуском на устройстве нужно проверить:

- 320–375 dp, альбомную ориентацию и большой системный шрифт;
- TalkBack: выбор модели, папки, меню чатов и параметры сообщения;
- клавиатуру, системные отступы и длинные пути;
- отсутствие модели, запуск движка, ошибку и выполняющуюся задачу;
- черновики, очередь сообщений, сохранение правил и резервную копию;
- поведение анимаций при отключённых системных анимациях.

Полная Android-сборка и эти проверки на устройстве в среде редактирования
не выполнялись: JDK, Gradle и Android SDK здесь не установлены.
